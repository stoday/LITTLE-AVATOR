# 09: Manage transcript retention and security audit records

**What to build:** A user can inspect and locally delete a discussion transcript with an honest notice about peer copies, while security and delivery audit facts remain useful without retaining unnecessary message bodies.

**Blocked by:** 04: Start and inspect a discussion from ordinary chat.

**Status:** in-progress

- [ ] Natural-language transcript retention defaults to 30 days and immediate local deletion is available through a user-visible flow.
- [ ] Security audit records retain identity, authorization, delivery, and commit facts without storing unnecessary transcript bodies.
- [ ] Restart and deletion tests verify each process manages only its own protocol history.
