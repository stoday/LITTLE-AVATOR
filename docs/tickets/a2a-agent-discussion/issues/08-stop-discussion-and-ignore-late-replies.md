# 08: Stop a discussion and ignore late replies

**What to build:** A user can stop an active collaboration from the desktop, preventing further turns; any late remote response is retained only as an audit fact when necessary and cannot reactivate the stopped interaction.

**Blocked by:** 04: Start and inspect a discussion from ordinary chat.

**Status:** in-progress

- [ ] The visible stop control ends local waiting and prevents a subsequent peer call.
- [ ] A late reply does not restart progress, add a final summary, or create a new local action.
- [ ] The result distinguishes a successfully stopped local interaction from a remote model call that could not be interrupted.
