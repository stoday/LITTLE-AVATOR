**What to build:** A user can ask Momo in ordinary chat to consult a peer, see progress outside the ordinary transcript, expand the exchanged peer Messages, and receive a final summary in the originating chat.

**Blocked by:** 03: Run an isolated multi-turn A2A discussion.
